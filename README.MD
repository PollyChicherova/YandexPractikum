# Автотест API «Самокат»

Один автотест для API сервиса аренды самокатов «Самокат», написан на `pytest` + `requests`.

## Структура проекта

- `config.py` — адрес API и пути методов
- `data.py` — тестовые данные нового заказа
- `api_requests.py` — функции для запросов к API (`send_new_order`, `find_order_by_track`)
- `tests/test_order.py` — сам тест

## Что делает тест

1. Выполняет запрос на создание заказа.
2. Сохраняет номер трека заказа.
3. Выполняет запрос на получение заказа по треку заказа.
4. Проверяет, что код ответа равен 200.

## Установка

```
pip install -r requirements.txt
```

## Запуск теста

```
pytest -v
```

## Логи сервера

Если тест падает из-за ошибок на стороне бэкенда, логи можно посмотреть тут:

`/var/www/backend/logs/error.log`
