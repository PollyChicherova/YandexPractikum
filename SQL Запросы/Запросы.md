# Запрос № 1

```
SELECT
	c.login as "courierLogin",
	COUNT(o.id) as "ordersInDeliveryCount"
FROM "Couriers" as c LEFT JOIN "Orders" as o
	ON c.id = o."courierId" AND o."inDelivery" = true
GROUP BY c.login;
```

# Запрос № 2

```
SELECT
	track,
	CASE
		WHEN o.finished = true THEN 2
		WHEN o.cancelled = true THEN -1
		WHEN o."inDelivery" = true THEN 1
		ELSE 0
	END as status
FROM "Orders" as o;
```
